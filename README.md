## 💻 Getting Started

To run this project locally:

```bash
git clone https://github.com/codewithmashi/bookstore.git
cd bookstore
flutter pub get
flutter run
```

## 🚀 Tech Stack

- Flutter (Latest stable version)
- Dart
- GetX (for state management & routing) *(optional if used)*
